# Loose Ends

An exhibition price list for **Loose Ends** by **Stelios Chatzivasileiou**, held **27–29 November 2026** at **Imposter Studio, Athens, Greece**.

The catalogue includes 13 artworks with photographs, mediums, dimensions and prices, plus exhibition descriptions in English and Greek.

Developed by [Alex Voinas](https://www.alexvoinas.com/) ([@alexev_studio](https://www.instagram.com/alexev_studio/)) for [Imposter Studio](https://www.instagram.com/studio.imposter/).
